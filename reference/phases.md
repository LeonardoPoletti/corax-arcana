# Corax Arcana — Phases

## Phase 1 — Product core (implement first)

Features without which the SaaS has no reason to exist: collection inventory, real-time market value, deck builder with legality validation, mana curve analysis, deck cost vs. cards you have, spending log, financial dashboard. Easy-to-medium difficulty, essential for every player profile.

Also here (traction prerequisites): social login, freemium mode, import from other platforms (Moxfield, MTGO, CSV).

## Phase 2 — Differentiation and retention

Price alerts, budget-based deck suggestions via AI, EDH groups, beginner tutorial, set rotation reminders, PWA.

## Phase 3 — Community and viral growth

Social deck feed, share deck as image for social media, rules forum, store/event map, trade marketplace. More complex, but generates the network effect that makes the platform hard to abandon.

## Phase 4 — Ambitious / differentiated features (implement last)

AI hand analysis, marketplace with escrow, ban prediction, real-time deck collaboration, public API, collection insurance, ML/OLX integration. Some are clearly "out of the box" — interesting for the roadmap, but don't block launch.

## Execution order

- Phase 01 → Foundation
- Phase 02 → Differentiation
- Phase 03 → Community
- Phase 04 → Scale
